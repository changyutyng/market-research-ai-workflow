# 用免費版 ChatGPT 跑市場研究流程

免費版不能建 Custom GPT，所以改用最簡單的做法：**每個階段開一次新對話，把「規則」和「該階段的 prompt」一起貼進去。**

需要的檔案只有兩個：

- 這份（怎麼用）
- `prompts.md`（要貼的內容都在裡面）

其他檔案是參考資料，想了解背後原理再看：`failure-modes.md`（實際發生過的錯誤，建議看一次）、`field-design.md`、`source-rules.md`、`templates.md`。`custom-gpt.md` 是付費版才用得到的，可以略過。

---

## 每個階段的固定動作

1. **開一個新對話。** 不要七個階段擠在同一串，聊太長它會忘記規則
2. **確認有開搜尋。** 輸入框下方的「搜尋／Search」要點亮。沒開的話它會用舊資料回答，而且不會告訴你
3. **貼兩段：** 先貼 `prompts.md` 最上面的〈專案指示〉那段規則，接著貼這個階段的 prompt
4. **把上一階段的結果貼在最後。** 直接貼文字就好，不用上傳檔案（免費版上傳次數有限）
5. **做完把結果存起來。** 複製到 Google Docs 或記事本，一個階段一份，下一階段要用

> 如果你的 ChatGPT 左側有「Projects／專案」，也可以開一個專案，把規則貼進專案指示，就不用每次重貼。沒有的話照上面做就好。

---

## 七個階段

| 階段 | 做什麼 | 是否停下檢查 |
|---|---|---|
| 1 假設化 | 把「我們相信但沒驗證過的事」列成假設 | **必須停下**：團隊真正想要知道什麼事實？只有你能判斷 |
| 2 對象與判準 | 決定要研究哪些對象、怎麼分類 | 快速確認分類判準是否合理 |
| 3 欄位設計 | 決定每個對象要查哪些項目 | **必須停下**：確認每一欄都對得上某條假設 |
| 4 查證 | 實際上網查資料 | **必須停下**：親自點開網址驗證（見下方） |
| 5 進表 | 整理成 CSV，貼進 Google Sheets | 快速確認數字在整理過程中有沒有出錯 |
| 6 寫文件 | 寫成報告 | 快速確認每個結論能不能在資料表中找到出處 |
| 7 審查 | 逐段閱讀，看不懂就提問 | **必須停下**：只有實際閱讀報告的人，才能判斷哪裡看不懂 |

## 三個最容易做錯的地方

**一、不要整份貼進去說「照這個做」。**
它會一口氣把七個階段都「做完」，給你一份完整漂亮、但沒有一處被驗證過的報告。

**二、階段 4 一定要分批，而且免費版要更小批。**
一次查 2 到 3 個對象就好。免費版每幾小時有訊息上限，批次太大做到一半被切斷，整批就得重做。

**三、網址要親自點開驗證。**
AI 很會生成「看起來很合理但其實是捏造的」網址。每批隨機點開五到十個：

- 打不開，或打開後是首頁而不是那篇文章 → 算錯誤
- 打得開但內容沒有提到它所說的事 → 也算錯誤

錯誤超過兩成，就開新對話整批重新查證，並在開頭加一句：

```
上一批有 N 個網址無法驗證。這批請降低產出量、提高可驗證性。
沒有實際開啟過的網址不要給，做不到就寫查無。
```

## 階段 5 的 CSV 怎麼變成表格

ChatGPT 給你 CSV 文字後：開一個 Google Sheets → 選 A1 → 貼上 → 跳出「將文字分割成欄」就點它。三個分頁各貼一次。
