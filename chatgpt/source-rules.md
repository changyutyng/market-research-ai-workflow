# 來源規則與判定三級

階段 4、5 適用。每一批查證都要重申一次 —— 不重貼，跑到後面標準會放寬。

## 來源規則（原文，可直接貼給任何 AI）

```
1. 收費、規章、票價、日期這類數字，只採用官方簡章、官網或官方新聞稿。
   二手整理的文章不算數。
2. 業者自己宣稱的成果（人次、成交率、市占、滿意度），
   一律標註「業者自述」，並註明未經第三方查核。
3. 每一條事實都要附網址與取得日期。
4. 查不到就寫「查無」，並列出你查過哪些地方。
   不要用推測、不要用「一般而言」把空格填滿。
5. 我會點開你給的每一個網址驗證。
   給不出可驗證網址的內容，一律寫查無，不要生成看起來合理的網址。
```

第 5 條是關鍵。明確講「我會點開驗證」，可驗證比例會明顯不同。

## 來源的優先順序

| 層級 | 類型 | 處理方式 |
|---|---|---|
| 1 | 官方簡章 PDF、報名辦法、合約範本 | 直接採用，記下版本年份 |
| 2 | 官網、官方售票頁、主管機關公開文件 | 直接採用，記取得日期（官網會改） |
| 3 | 具名記者的媒體報導 | 採用，記媒體名與日期 |
| 4 | 業者自述的成果數字 | 採用但標註「業者自述」 |
| 5 | 內容農場、二手整理、AI 摘要 | 不採用。只能當線索，要回溯到 1–3 層 |

歷年資料查不到時，用 Wayback Machine 的 CDX 介面找歷史存檔，通常能撈到已下架的簡章 PDF。

## 判定三級

對假設下結論時只能三選一：

| 判定 | 定義 | 典型情況 |
|---|---|---|
| **已驗證** | 有先例，且結果支持假設 | 找得到同類做法，且它的結果與假設一致 |
| **資料不足** | 無直接先例，或證據相關但無法建立因果 | 找得到相關資料，但推不出因果；或根本沒人做過 |
| **推翻** | 有先例，且結果與假設相反 | 找得到同類做法，結果打臉假設 |

「大概可以」「應該沒問題」「值得樂觀」一律歸到**資料不足**。

### 為什麼要有「資料不足」這一級

只分成立／不成立，會逼人把「還不知道」講成「大概成立」。

分出這一級，等於允許研究誠實地說不知道 —— 而不知道本身就是決策資訊：**它告訴你哪些事必須靠實測，不能靠研究**。

實務上，資料不足的那幾條會變成專案啟動後必須現場量測的指標清單。這份清單通常比「已驗證」的那幾條更有行動價值。

## 引文的額外規則

引用任何人的發言（消費者、從業者、創作者）時：

1. **逐字引用，不改寫不摘要。** 改寫過的引文沒有證據力
2. **驗證發言者身分。** 說服力完全建立在身分上
3. **說明如何確認這段話確實在那個頁面上**（例如實際讀取頁面並比對字串）
4. **身分存疑的一律不採用**，寧可少三條

引文的身分沒驗證，引文就只是裝飾。
