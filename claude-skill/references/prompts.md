# 七段 prompt（帶去別的 AI 用）

使用者要在 ChatGPT、Gemini 或其他工具執行這套流程時，把這份提供給他。
完整的使用說明見 `../install/other-ai.md`。

每段一次貼一個，做完檢查再進下一段。不要整份貼進去說「照這個做」。

---

## 專案指示（放進 Projects 的指示欄，全程生效）

```
你在協助我做一份市場研究。這份研究要能被查證，也要能被推翻。

【來源】
1. 收費、規章、票價、日期這類數字，只採用官方簡章、官網或官方新聞稿。二手文章不算數
2. 業者自述的成果（人次、成交率、市占），一律標註「業者自述」，並註明未經第三方查核
3. 每一條事實都要附網址與取得日期
4. 查不到就寫「查無」，並列出你查過哪些地方。不要用推測把空格填滿
5. 我會點開你給的每一個網址驗證。給不出可驗證網址的內容，一律寫查無

【判定】
對假設下結論只能三選一：已驗證／資料不足／推翻
「大概可以」「應該沒問題」一律歸到資料不足

【寫法】
先講結論再講依據；推論要標「推論」；不用「總體而言」這類沒有資訊的句子；避免行話

【不要做】
不要為了段落完整補沒查證的內容；不要把統計基準不同的數字放在一起比；
不要把「我查不到」寫成「不存在」
```

---

## 1　假設化

```
我要做一份市場研究，但先不要開始查資料。

第一步只做一件事：把下面這段描述裡，所有「我們相信但還沒驗證」的事情，
逐條列成可檢驗的假設。

要求：
1. 每條假設要能被「有先例／沒先例」判定，不要寫成價值判斷
2. 每條後面寫明：要驗證它，需要看到什麼樣的證據才算數
3. 如果某個信念根本無法用桌面研究驗證，直接說明，不要勉強列進去

［貼上商業模式描述、團隊內部的爭論、你最不確定的地方］
```

## 2　對象與判準

```
依據上面的假設清單，列出需要研究的對象。

分類判準必須先講明白，而且只能用一個判準。
不要用「相似度」「相關性」這種可以各自解讀的詞。

每個對象標明：屬於哪一類及理由、能驗證哪幾條假設、資料公開程度。
如果有對象你認為該納入但我沒提到，列出來並說明理由。
資料完全不公開的對象，建議排除並說明原因。
```

## 3　欄位設計

```
在開始查資料之前，先設計這份研究的欄位。

規則：
1. 每一欄都要能讓所有對象橫向比較
2. 每一欄都要對應到至少一條假設。不對應任何假設的欄位不要放
3. 欄位要問「事實」不要問「評價」
4. 每一欄都要事先想好：如果查不到，要怎麼標示

列出一張表：欄位名稱｜這欄要回答什麼｜對應假設｜資料可能在哪裡｜查無時怎麼寫
```

## 4　查證（分批，每批 3 到 5 個對象）

```
以下是研究對象清單與欄位表。這一批請查證這幾個對象：［列出 3 到 5 個］

來源規則，每一條都要遵守：
1. 數字只採用官方簡章、官網或官方新聞稿，二手文章不算
2. 業者自述的成果一律標註「業者自述」
3. 每條事實附網址與取得日期
4. 查不到就寫「查無」，並列出你查過哪些地方
5. 我會點開你給的每一個網址驗證。給不出可驗證網址的，一律寫查無

產出：每個對象一節，依欄位表逐欄填寫，查無的欄位保留並標示。
```

## 5　進表

```
把查證結果整理成三個分頁的資料表，以 CSV 格式產出，一個分頁一段。

分頁一　對照表：對象為欄、欄位為列
分頁二　假設判定：編號｜假設｜證據摘要｜判定｜意涵｜出處
分頁三　來源：對象｜來源名稱｜網址｜取得日期｜用在哪一欄或哪一章

判定只能三選一：已驗證／資料不足／推翻
```

## 6　寫文件

```
依據資料表寫成報告。

內容規則
・所有數字必須回得到來源分頁的某一列。表上沒有的數字不要出現
・屬於推論而非資料直接支持的，句首標「推論」
・每一章結尾要有一段「對我們的意涵」，寫明會改變哪個決定，不要只摘要前面
・查無的事情要寫出來，並說明查過哪些地方

結構
每章固定三段：這個對象是什麼 → 跟我們哪裡相同哪裡不同 → 對我們的意涵
最後加一章「假設驗證」，把分頁二整理成表，並說明三種判定的定義。
```

## 7　審查（沒有 prompt，由人做）

逐段讀，看不懂就把那句貼回去問「**這句是什麼意思？**」

交替使用的三句：
- 這句是什麼意思？
- 這個結論的證據是什麼？
- 這是查到的，還是你推論的？

## 補充　查不到的時候

```
以下這個結論目前的證據是「查不到」。
「查不到」不等於「不存在」，可能只是管道不對。

請換一批管道再查一次：論壇的分板與站內搜尋、部落格平台的標籤頁、
社群平台的站內搜尋、產業公會或主管機關的公開文件。

每找到一條：附原文逐字（不改寫不摘要）、網址、
說明你用什麼方式確認這段話確實在那個頁面上、發言者身分與如何確認。

找不到也要回報你查了哪些管道、各自的結果數。
```
